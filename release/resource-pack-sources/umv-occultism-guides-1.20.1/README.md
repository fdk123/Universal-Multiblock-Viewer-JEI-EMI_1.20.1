# Occultism guides for 1.20.1

This resource pack contains 13 ritual pentacles for Occultism 1.158.0 on
Minecraft 1.20.1. The structures were generated from Occultism's own
`data/occultism/modonomicon/multiblocks` definitions by
`release/generate_occultism_1_20_1.py`.

Install the ZIP in your Minecraft `resourcepacks` directory, enable it in the
client, and install the Forge 1.20.1 backport of Universal Multiblock Viewer.
These are resource-pack assets, not server datapack definitions.
